# 人脸识别门禁系统 - 数据库初始化指南

## 方法一：使用命令行（推荐）

### 1. 打开命令提示符（CMD）
按 `Win + R`，输入 `cmd`，按回车

### 2. 进入数据库目录
```cmd
cd c:\Users\29844\Desktop\毕业设计\zbmj\database
```

### 3. 执行初始化脚本

**如果MySQL没有密码：**
```cmd
"C:\Program Files (x86)\mysql-8.4.5-winx64\bin\mysql.exe" -u root < face_access_system.sql
```

**如果MySQL有密码（例如密码是 root）：**
```cmd
"C:\Program Files (x86)\mysql-8.4.5-winx64\bin\mysql.exe" -u root -proot < face_access_system.sql
```

**如果MySQL有密码（交互式输入）：**
```cmd
"C:\Program Files (x86)\mysql-8.4.5-winx64\bin\mysql.exe" -u root -p < face_access_system.sql
```
然后输入密码

## 验证数据库是否创建成功

执行以下命令：
```cmd
"C:\Program Files (x86)\mysql-8.4.5-winx64\bin\mysql.exe" -u root -p -e "SHOW DATABASES LIKE 'face_access_system';"
```

如果看到 `face_access_system` 数据库，说明创建成功！

## 常见问题

### 1. 提示"mysql不是内部或外部命令"
需要将MySQL的bin目录添加到系统环境变量PATH中

### 2. 提示"Access denied for user 'root'"
密码错误，请检查MySQL root密码

### 3. 提示"Can't connect to MySQL server"
MySQL服务未启动，请启动MySQL服务：
```cmd
net start mysql
```
或
```cmd
net start mysql84
```
